# **App Name**: DataLake CRM

## Core Features:

- User Authentication: Secure user registration and login with username and password.
- CRM Dashboard: Display relevant CRM information and a 'Settings' button for configuration.
- Data Lake Interface: Configuration section with a 'Data Lake' tab displaying data folders.
- Data Download: Allow users to download data from each folder in the Data Lake.
- Connection Status Indicator: Visual indicator displaying the connection status to the Data Lake, changing color based on status (green for connected, red for disconnected).

## Style Guidelines:

- Primary color: Dark teal (#008080) to represent reliability and security in handling data.
- Background color: Light gray (#F0F0F0), a very desaturated version of the primary color, to ensure comfortable readability.
- Accent color: Blue (#4682B4) to highlight interactive elements and calls to action, while complementing the teal.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text. 'Source Code Pro' for code snippets.
- Simple, clear icons for data folders, settings, and status indicators.
- Clean, intuitive layout with clear sections for the dashboard, settings, and data lake management.
- Subtle animations for loading data and status changes to provide user feedback.
